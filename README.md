# Nationwide Computers — Website Demo

A modern, responsive website concept designed for **Nationwide Computers**, a computer retail business.

The project showcases a clean digital storefront experience where customers can explore computer products, browse categories, discover business solutions, and make product enquiries through WhatsApp.

> **Note:** This is an independent website demo concept, not the official Nationwide Computers website.

## 🌐 Live Demo

[View Website](https://YOUR-USERNAME.github.io/nationwide-computers/)

Replace `YOUR-USERNAME` with your GitHub username after deployment.

## ✨ Features

- Modern, responsive user interface
- Home, Shop, Product Details, Business Solutions, About and Contact sections
- Product catalogue with search and filtering
- Category and brand filters
- Product enquiry through WhatsApp
- Business quotation request form
- Contact enquiry form
- Dark and light theme toggle
- Smooth page transitions and animations
- Mobile-friendly navigation
- Floating WhatsApp contact button

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- Unsplash and external product photography

## 📱 Contact Integration

The website includes WhatsApp and telephone links using a Ghanaian mobile number in international format.

Product enquiries and contact forms prepare messages that customers can send directly through WhatsApp.

## 🚀 Deployment

This project can be hosted using GitHub Pages.

1. Create a public GitHub repository.
2. Upload `index.html` and `README.md`.
3. Navigate to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Save and wait for deployment.

## ⚠️ Demo Information

The product catalogue contains illustrative product listings and external product images.

Before production use:

- Verify product names and specifications.
- Replace sample listings with confirmed inventory.
- Confirm product availability and pricing.
- Use approved company photography.
- Confirm company contact details and business information.

The forms currently open WhatsApp messages. They do not store submissions in a database.

## 🎯 Project Objective

The objective of this concept is to demonstrate how Nationwide Computers could establish a modern online presence, improve product discovery, and make it easier for potential customers and businesses to make enquiries.
